# drawbluffs Begriffe auf Deutsch: für Deutschsprachige geschrieben,
# nicht übersetzt. Der Host lädt sie für Räume auf Deutsch
# (data/prompts.txt: Englisch).
#
# Format wie data/prompts.txt: `[tag]` beginnt eine Struktur, dann ein
# Begriff pro Zeile, dahinter seine drei Köder, jeder nach ` | `;
# Leerzeilen und `#`-Kommentare zählen nicht.
#
# Köder sind die Lügen, die das Spiel ergänzt, wenn eine Zeichnung zu
# wenige hat: andere Titel für das Bild, das man zum Begriff malen
# würde (ein Ding gegen ein ähnlich aussehendes getauscht, das Bild als
# andere Geschichte), mindestens zwei in der Struktur des Begriffs;
# nie der Begriff umformuliert, nie ein Begriff der Datei, keiner
# doppelt. Für sie gelten dieselben Regeln wie für die Begriffe.
#
# Jeder Begriff steht in seiner Anzeigeform (klein geschrieben, nur
# Buchstaben mit ä, ö, ü, ß, Leerzeichen und Apostrophe, nichts am
# Ende, NFC) und hat höchstens 40 Zeichen (LIE_SOFT), so verrät weder
# Form noch Länge die Wahrheit. Zeichenbar, familientauglich, unser
# eigenes; keine zwei gleichen (test/prompts.test.ts prüft das).
#
# Begriffe und Köder stehen in den Formen, in denen Spieler ihre Lügen
# tippen, damit weder die Wahrheit noch die Köder nach der Datei
# aussehen: etwa ein Drittel mit Artikel vorn ("ein vampir beim
# zahnarzt"), der Rest ohne ("vampir beim zahnarzt"), im Plural
# ("vampire beim zahnarzt"), als kurzes Etikett ("schwitzender
# schneemann"), als Satz ("der schneemann schmilzt", "oma entdeckt
# emojis"), "wenn …", "mein …", im Telegrammstil ("katze macht
# steuer"); kurze und lange. Ein Begriff steht in den Formen seiner
# Köder, und mindestens ein Köder hat wie er einen Artikel vorn oder
# keinen (`node scripts/prompts.ts --lang de` misst die Formen, die
# Lints halten beide gleich).
#
# Die Strukturen:
#   odd       seltsame Paare: ein hai im nichtschwimmerbecken
#   idiom     Redewendungen wörtlich: tomaten auf den augen
#   wort      zusammengesetzte Wörter wörtlich: glückspilz
#   feeling   Gefühle und Begriffe: fernweh
#   moment    der Moment, wenn: der bus fährt vor der nase weg
#   secret    das geheime Leben der Dinge: was mein kühlschrank nachts treibt
#   invented  erfundene Berufe, Sportarten, Feiertage: pfützeninspektor
#   contra    Widersprüche: wasserscheuer hai
#   view      ungewohnte Blickwinkel: die welt aus sicht einer ameise
#   drama     kleine Dramen: wespe am pflaumenkuchen
#   title     berühmt klingende Titel: herr der zwiebelringe
#   animal    Tiere mit Menschenproblemen: ein zebra am zebrastreifen
#   food      Essen mit Eigenleben: suppe schlägt zurück
#   place     Orte, die es nicht geben sollte: die schule für babydrachen
#   gadget    Erfindungen, die keiner braucht: ein föhn für katzen
#   power     nutzlose Superkräfte: unsichtbar aber nur dienstags
#   then      Geschichte durcheinander: ritter beim tüv
#   scene     Alltag geht schief: schrank aufbauen ohne anleitung
